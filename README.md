
# Personal Portfolio - Achruddin

Website personal portfolio modern dan responsif milik Achruddin, mahasiswa Program Studi Ilmu Komputer, Universitas Halu Oleo.

Website ini dibuat sebagai media untuk memperkenalkan profil diri, kemampuan, pengalaman, pendidikan, serta proyek yang pernah dikerjakan.

## 🚀 Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome (ikon, jika digunakan)
- Google Fonts (Poppins, jika digunakan)

## 💻 Cara Menjalankan Website

1. Download atau clone repository ini.
2. Buka folder `personal-portfolio`.
3. Pastikan semua file berada pada lokasi yang benar.
4. Buka file `index.html` menggunakan browser.
5. Website siap digunakan.

Kamu juga dapat menggunakan ekstensi **Live Server** di Visual Studio Code untuk menjalankan website selama proses pengembangan.

## ✏️ Cara Mengedit Website

### 1. Mengubah Profil

Buka `index.html`, kemudian cari bagian Hero dan About.

Ubah nama, deskripsi, informasi pribadi, dan foto profil sesuai identitas kamu.

### 2. Mengubah Foto Profil

Simpan foto profil di:

```text
assets/images/
```

Kemudian sesuaikan atribut `src` pada elemen gambar di `index.html`.

### 3. Mengubah Skills

Cari bagian Skills pada `index.html`.

Sesuaikan nama keterampilan dan nilai progress berdasarkan kemampuan yang dimiliki.

### 4. Menambahkan Proyek

Cari bagian Projects pada `index.html`.

Ubah judul, deskripsi, teknologi, gambar, dan tautan proyek sesuai karya yang ingin ditampilkan.

### 5. Mengubah Warna dan Tampilan

Buka `style.css`.

Kamu dapat mengubah warna utama, background, ukuran teks, jarak, dan tampilan responsif melalui CSS Variables di bagian `:root`.

### 6. Mengatur Fitur Interaktif

Buka `script.js` untuk mengubah fungsi navigasi, dark mode, animasi, dan formulir kontak.
